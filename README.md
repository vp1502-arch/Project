# Project

This repository now includes a minimal Node.js app that runs locally.

## Prerequisites

- Node.js 18 or newer
- npm (comes with Node.js)

## Run locally

1. Install dependencies:
   - `npm install`
2. Start the app:
   - `npm start`
3. Open:
   - `http://127.0.0.1:3000`
4. Health check endpoint:
   - `http://127.0.0.1:3000/health`
