# AI Hub — Unilever Mumbai

A single internal platform to discover and learn about all the AI tools available in the Unilever Mumbai facility — descriptions, links, points of contact (POCs), training docs, training scheduling, and FAQs — with a two-way (employee + admin) access model.

## Status

Early stage. The product requirements are defined first; implementation follows in phases.

- 📄 **Product Requirements Document:** [`docs/PRD.md`](docs/PRD.md)

## Planned tech stack

React + Vite + TypeScript (frontend), Node.js + Express + TypeScript with Prisma (backend), SQLite for local dev (PostgreSQL-ready), Tailwind CSS for Unilever-themed UI. See the PRD for full details and rationale.
